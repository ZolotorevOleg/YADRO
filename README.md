# Золоторев Олег

## Обо мне

Меня зовут Золоторев Олег, я студент 3 курса и изучаю сферу DevOps около 3 лет. По большей части обучался сам - изучал лекции, выполнял задания на rotoro.cloud, VK Courses, Stepik, открытых видеороликах на YouTube, а затем стал внедрять полученные знания в свои проекты и в свою повседневную жизнь.

## Стажировка

Я проходил стажировку на позиции сетевого инженера с уклоном в DevOps. В этот период я участвовал в мониторинге и обслуживании сетевой инфраструктуры, диагностике проблем с подключением и настройке сетевого оборудования. Параллельно изучал и применял практики автоматизации и управления инфраструктурой, что позволило мне лучше понять взаимодействие между разработкой и эксплуатацией систем.

В процессе стажировки и работы над проектами я использовал ряд инструментов и технологий, применяемых в DevOps:

- Docker  
- Docker Compose  
- Git  
- Linux  
- Python
- Zabbix
- Grafana
- Ansible

Кроме того, я работал с сетевым оборудованием и инструментами мониторинга, что помогло мне получить практическое представление о поддержке и эксплуатации инфраструктуры.

## Личные проекты

Многие из моих личных проектов возникли из-за простых задач, которые я ставил перед собой. 

Например, при работе над одной из моих первых задач по автоматизации мне нужно было обеспечить согласованное развертывание небольшого приложения в разных средах. Я изучил технологии контейнеризации и решил задачу, создав стабильную конфигурацию развертывания, которая упростила обслуживание и сократила количество ошибок.

В другом из проектов мне нужно было разделить большое приложение на несколько более простых частей. Я разбил его на отдельные компоненты и настроил их взаимодействие так, чтобы вся система работала стабильно. Хотя проект был небольшим, этот опыт помог мне лучше понять важность модульности, разделения функций между компонентами и удобства поддержки системы.
